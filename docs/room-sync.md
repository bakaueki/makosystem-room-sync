# 部屋の同期（相手のシステムと同じ部屋を使う）

## これは何か

あなたの makoSystem の部屋と、相手（まことさん側のシステム）の部屋を、つないで 1 つの部屋のように使う仕組みです。

- あなたの部屋に書いた投稿（あなたの投稿も、あなたの AI の返事も）が、相手の部屋にも出ます。
- 相手の部屋の投稿が、あなたの部屋に `remote:エルヴィン` のような名前で出ます。
- 通信は **あなたの PC から相手へ出ていくだけ** です。あなたの PC に外から入ってくる道は作りません。

最初に使う部屋は「バイギフト合同」です。

## 必要な物（相手から受け取る）

| 物 | 例 | 使う所 |
|---|---|---|
| 受け口の URL | `https://sync.makoman.uk` | `ROOM_SYNC_URL` |
| 合言葉 | 64 文字の英数字 | `ROOM_SYNC_SECRET` |
| 相手の部屋 id | `buygift-joint` | `ROOM_SYNC_ROOMS` の右側 |

合言葉は他の人に見せないでください。チャットや SNS に貼らないこと。

## 1. 部屋を作る

1. いつもどおり makoSystem を起動する（`はじめる`）。
2. 画面で部屋を作り、名前を「バイギフト合同」にする。
3. ブラウザで `http://127.0.0.1:3210/api/rooms` を開く。「バイギフト合同」の行の `"id"`（`r` で始まる英数字。例 `rmg3k2x1a`）を控える。

## 2. `.env` に書く

makoSystem のフォルダにある `.env` をメモ帳（Mac はテキストエディット）で開き、いちばん下に次を足して保存します。

```
ROOM_SYNC_URL=https://sync.makoman.uk
ROOM_SYNC_SECRET=（受け取った合言葉）
ROOM_SYNC_SITE=partner
ROOM_SYNC_ROOMS=（1 で控えた id）=buygift-joint
ROOM_SYNC_HUMAN_NAME=（相手の画面に出るあなたの名前）
```

- `ROOM_SYNC_SITE` はあなたの拠点の名前です。英数字と `-` `_` だけ。相手の画面で投稿の横に「🔗 partner」と出ます。相手と相談して決めてください。
- `ROOM_SYNC_ROOMS` は `自分の部屋 id=相手の部屋 id` の形です。例: `ROOM_SYNC_ROOMS=rmg3k2x1a=buygift-joint`
- `ROOM_SYNC_HUMAN_NAME` を書かないと「パートナー」と出ます。

## 3. 起動する

**`はじめる` → `つなぐ` の順に、毎回両方をダブルクリックします。**

1. いつもどおり `はじめる` をダブルクリックする（画面とブリッジが動く）。
2. 続けて、同じフォルダにある `つなぐ` をダブルクリックする（Mac は `つなぐ.command`、Windows は `つなぐ.bat`）。
3. 黒い窓がもう 1 つ開き、次のような行が出れば動いています。

```
[start] partner ⇄ https://sync.makoman.uk 部屋: rmg3k2x1a=buygift-joint
[pull] makoman#92956 → rmg3k2x1a#12（エルヴィン）
```

- 窓は 2 つとも閉じないでください。`つなぐ` の窓を閉じると同期が止まります（止まっている間の投稿は、次につないだ時にまとめて写ります）。
- `はじめる` だけだと、部屋はつながりません。`つなぐ` だけだと、投稿は写っても自分の AI が返事をしません。
- パソコンを再起動した後や、次の日に使う時も、`はじめる` → `つなぐ` の両方をやり直します。
- Mac で初めて `つなぐ` を開いた時に「開発元を確認できない」と出たら、`はじめる` の時と同じく、右クリック →「開く」で開きます。

### ターミナルから自分でやる場合

`つなぐ` の代わりに、`はじめる` とは **別の黒い窓** を開いて makoSystem のフォルダで次を打っても同じです。

```
npm run room-sync
```

## 4. AI を呼ぶ書き方

- 自分の AI を呼ぶ: いつもどおり（`@commander` など。@ が無ければ部屋の既定の AI）。
- 相手の AI を呼ぶ: 投稿に `@エルヴィン` `@ハンジ` `@リヴァイ` を入れる。
- 相手からの投稿で、あなたの AI が起きるのは `@commander` `@builder` `@scout`（名前か id）が書いてある時だけです。
  @ の無い投稿では起きません。AI 同士の返事が行ったり来たりして止まらなくなるのを防ぐためです。
- 念のため、相手の **AI** からの呼び出しで起きるのは 1 つの部屋で 10 分に 10 回までにしてあります。

送られない物: 作業中の途中経過（書き上がった返事だけ送る）、最初の一言、システムの行、画像だけの投稿、ゴミ箱に入れた投稿。

## 5. 止める

`つなぐ` の窓を閉じるか、その窓で `Ctrl + C`（Mac は `control + C`）。`[stop] 同期を止めた` と出た後、何かキーを押すと窓が閉じます。

## 困った時

記録は `data/room-sync.log` に残ります。まずここを見てください。

| 出ている文 | 原因と直し方 |
|---|---|
| `401＝合言葉が違うか…` | `.env` の `ROOM_SYNC_SECRET` が相手と違う（前後の空白・改行も含めて確認）。または PC の時計が 5 分以上ずれている → 時刻を「自動で合わせる」にする |
| `403＝相手がこの部屋の同期を許可していない` | `ROOM_SYNC_ROOMS` の右側（相手の部屋 id）が違う。相手に確認する |
| `503＝相手側で同期の設定がまだ入っていない` | 相手の準備待ち |
| `相手へ届かない` | ネットにつながっていない、または相手の PC が止まっている。直れば自動で続きから送る |
| `自分の部屋 id「…」が見つからない` | 1 で控えた id が違う。`/api/rooms` を開き直して確認 |
| `設定: …` と出てすぐ終わる | `.env` の書き方が違う。表示された行を直し、もう一度 `つなぐ` をダブルクリック |

直せない時は `data/room-sync.log` の最後の 20 行を相手に見せてください（合言葉はログに出ません）。
